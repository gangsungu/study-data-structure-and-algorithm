## 탐색의 활용

[BFS와 DFS](그래프의-탐색.md)는 그 자체로 답을 주지 않는다. **"돌면서 무엇을 기록하느냐"** 가 문제를 푼다.
`visited`를 `boolean`이 아니라 거리 배열로 바꾸면 최단 경로가 나오고, 탐색을 몇 번 시작했는지 세면 연결 요소 개수가 나온다.
아래는 그 기록 방식만 바꿔 만드는 대표 패턴들이다.

예제는 모두 인접 리스트와 1번부터 시작하는 정점 번호를 쓴다.

### 비가중 최단 경로 (BFS)
+ BFS는 **가까운 정점부터 한 겹씩** 퍼지므로, 어떤 정점에 **처음 도달한 순간이 곧 최단 거리**다
+ `boolean visited` 대신 **`int[] dist`** 를 쓰면 방문 여부와 거리를 한 배열로 처리할 수 있다
    - `-1`은 "아직 도달하지 못함"이라 방문 배열 역할까지 겸한다

```java
import java.util.*;

static int[] bfsDistance(List<List<Integer>> graph, int start) {
    int[] dist = new int[graph.size()];
    Arrays.fill(dist, -1);          // -1 = 아직 도달하지 못함
    Queue<Integer> queue = new ArrayDeque<>();

    dist[start] = 0;
    queue.offer(start);

    while (!queue.isEmpty()) {
        int node = queue.poll();
        for (int next : graph.get(node)) {
            if (dist[next] == -1) {             // 아직 안 왔다면
                dist[next] = dist[node] + 1;    // 여기까지 오는 데 한 칸 더
                queue.offer(next);
            }
        }
    }
    return dist;
}
```

```
       (1)         dist[1] = 0
      ╱   ╲
    (2)   (3)      dist[2] = dist[3] = 1
     │     │
    (4)   (5)      dist[4] = dist[5] = 2
```

+ **DFS로는 이렇게 안 된다.** DFS가 먼저 도달한 경로는 최단이라는 보장이 없다
+ 간선마다 가중치가 다르면 BFS로 풀 수 없다 → 다익스트라

#### 경로 복원
+ 거리만이 아니라 **"어떤 길로 갔는지"** 가 필요하면 직전 정점을 기록한다

```java
int[] prev = new int[graph.size()];
Arrays.fill(prev, -1);

// BFS 안에서 거리와 함께 기록
// dist[next] = dist[node] + 1;
// prev[next] = node;

// 도착점에서 거꾸로 따라 올라간 뒤 뒤집는다
List<Integer> path = new ArrayList<>();
for (int at = end; at != -1; at = prev[at]) path.add(at);
Collections.reverse(path);        // [1, 3, 5]
```

### 연결 요소 세기 (DFS · BFS)
+ **연결 요소(Connected Component)** = 서로 도달 가능한 정점들의 덩어리
+ 탐색 한 번은 덩어리 하나를 통째로 훑는다. 따라서 **탐색을 시작한 횟수 = 연결 요소 개수**다

```java
static int countComponents(List<List<Integer>> graph, int V) {
    boolean[] visited = new boolean[V + 1];
    int count = 0;

    for (int i = 1; i <= V; i++) {
        if (!visited[i]) {
            dfs(graph, i, visited);   // 덩어리 하나를 다 칠하고 돌아온다
            count++;
        }
    }
    return count;
}
```

```
 (1)───(2)     (4)      (5)───(6)
        │                      │
       (3)                    (7)

 탐색 시작: 1번에서 한 번, 4번에서 한 번, 5번에서 한 번 → 연결 요소 3개
```

+ DFS든 BFS든 상관없다. **덩어리를 다 칠하기만** 하면 된다
+ 친구 관계에서 무리 세기, 네트워크가 몇 조각으로 끊겼는지 확인하는 데 쓴다

### 2차원 격자 탐색
+ 코딩 테스트에서 가장 자주 나오는 형태다. 그래프처럼 안 생겼지만 **명백한 그래프**다
    - **정점 = 칸**, **간선 = 상하좌우로 인접한 관계**
    - 인접 리스트를 만들 필요가 없다. 좌표에 `±1`을 하면 그게 이웃이다
+ `dr` · `dc` 배열이 관용구다

```java
// 상 하 좌 우
static final int[] dr = {-1, 1, 0, 0};
static final int[] dc = { 0, 0, -1, 1};
```

```
        (r-1, c)
            │
(r, c-1)─(r, c)─(r, c+1)      네 방향이 곧 간선이다
            │
        (r+1, c)
```

+ 섬 개수 세기 — **연결 요소 세기와 완전히 같은 문제**다

```java
static int countIslands(int[][] grid) {
    int R = grid.length, C = grid[0].length;
    boolean[][] visited = new boolean[R][C];
    int count = 0;

    for (int r = 0; r < R; r++) {
        for (int c = 0; c < C; c++) {
            if (grid[r][c] == 1 && !visited[r][c]) {
                fill(grid, visited, r, c);   // 섬 하나를 통째로 칠한다
                count++;
            }
        }
    }
    return count;
}

static void fill(int[][] grid, boolean[][] visited, int sr, int sc) {
    int R = grid.length, C = grid[0].length;
    Deque<int[]> stack = new ArrayDeque<>();

    stack.push(new int[]{sr, sc});
    visited[sr][sc] = true;

    while (!stack.isEmpty()) {
        int[] cur = stack.pop();

        for (int d = 0; d < 4; d++) {
            int nr = cur[0] + dr[d], nc = cur[1] + dc[d];

            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;   // 격자 밖
            if (visited[nr][nc] || grid[nr][nc] == 0) continue;     // 이미 봤거나 바다

            visited[nr][nc] = true;
            stack.push(new int[]{nr, nc});
        }
    }
}
```

+ **범위 검사를 먼저** 한다. `grid[nr][nc]`를 먼저 읽으면 `ArrayIndexOutOfBoundsException`이 난다
+ 미로의 최단 거리를 묻는다면 스택을 큐로 바꾸고 `visited` 대신 `dist`를 쓴다. 위의 BFS 최단 경로와 같은 코드다
+ 격자가 1000×1000이면 칸이 100만 개다. **재귀 DFS는 스택이 터질 수 있으니** 스택이나 BFS를 쓴다

### 사이클 판별 (DFS)
방향 그래프와 무방향 그래프의 판별법이 **다르다.** 같은 코드로 풀면 틀린다.

#### 무방향 그래프 — 부모가 아닌 방문 정점을 만나면 사이클
+ 무방향 간선은 `A ↔ B` 양쪽에 등록돼 있어서, A에서 B로 갔다가 **B에서 A를 다시 보는 건 당연하다**
+ 그러니 **직전에 온 정점(부모)은 제외**하고, 그 외에 이미 방문한 정점을 만나면 사이클이다

```java
static boolean hasCycle(List<List<Integer>> graph, int node, int parent, boolean[] visited) {
    visited[node] = true;

    for (int next : graph.get(node)) {
        if (!visited[next]) {
            if (hasCycle(graph, next, node, visited)) return true;
        } else if (next != parent) {
            return true;        // 부모가 아닌데 이미 방문 → 사이클
        }
    }
    return false;
}

hasCycle(graph, 1, -1, new boolean[V + 1]);   // 시작점의 부모는 -1
```

#### 방향 그래프 — 지금 타고 내려온 경로에 다시 나타나면 사이클
+ "이미 방문함"만으로는 판별할 수 없다. **이미 끝낸 가지**를 다시 가리키는 건 사이클이 아니다
+ 그래서 상태를 둘로 나눈다 — **방문했다**와 **지금 재귀 경로 위에 있다**

```
  (1) → (2) → (3)
   ╲           ↑
    ╲──────────┘        1 → 3 은 이미 끝난 3을 가리킬 뿐, 사이클이 아니다

  (1) → (2) → (3)
         ↑     │
         └─────┘        3 → 2 는 지금 내려온 경로 위의 2로 돌아간다 → 사이클
```

```java
static boolean hasCycle(List<List<Integer>> graph, int node, boolean[] visited, boolean[] inPath) {
    visited[node] = true;
    inPath[node] = true;        // 지금 이 정점을 타고 내려가는 중

    for (int next : graph.get(node)) {
        if (!visited[next]) {
            if (hasCycle(graph, next, visited, inPath)) return true;
        } else if (inPath[next]) {
            return true;        // 현재 경로에 다시 등장 → 사이클
        }
    }

    inPath[node] = false;       // 되돌아 나오면서 경로에서 뺀다 (이 줄이 빠지면 오답이다)
    return false;
}
```

+ 사이클이 없는 방향 그래프가 **DAG**다. 위상 정렬은 DAG에서만 가능하다
+ 빌드 의존성이나 선수 과목에 순환이 있는지 확인할 때 쓰는 코드다

### 이분 그래프 판별 (BFS)
+ **이분 그래프** = 정점을 두 그룹으로 나눠 **모든 간선이 서로 다른 그룹을 잇게** 만들 수 있는 그래프
+ 인접한 정점을 번갈아 색칠하다가 **같은 색끼리 이어진 간선**을 만나면 이분 그래프가 아니다

```java
static boolean isBipartite(List<List<Integer>> graph, int V) {
    int[] color = new int[V + 1];
    Arrays.fill(color, -1);        // -1 = 아직 색칠 안 됨

    for (int start = 1; start <= V; start++) {
        if (color[start] != -1) continue;      // 비연결 그래프 대비

        Queue<Integer> queue = new ArrayDeque<>();
        color[start] = 0;
        queue.offer(start);

        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int next : graph.get(node)) {
                if (color[next] == -1) {
                    color[next] = 1 - color[node];   // 반대 색으로 칠한다
                    queue.offer(next);
                } else if (color[next] == color[node]) {
                    return false;                    // 같은 색끼리 이어짐
                }
            }
        }
    }
    return true;
}
```

+ **홀수 길이 사이클이 하나라도 있으면 이분 그래프가 아니다.** 삼각형을 두 색으로 칠해보면 바로 막힌다
+ 서로 적대하는 두 진영으로 나눌 수 있는지, 매칭이 가능한 구조인지 확인할 때 쓴다

### 패턴 고르기

|문제|탐색|기록하는 것|
|---|---|---|
|도달 가능한가|DFS · BFS|`boolean[] visited`|
|최소 몇 번 만에 도달하는가|**BFS**|`int[] dist`|
|어떤 경로로 갔는가|BFS · DFS|`int[] prev` (직전 정점)|
|덩어리가 몇 개인가|DFS · BFS|탐색을 시작한 횟수|
|격자에서 영역 세기 · 최단 거리|DFS · BFS|`dr` · `dc`로 상하좌우 이동|
|사이클이 있는가 (무방향)|**DFS**|부모 정점|
|사이클이 있는가 (방향)|**DFS**|`visited` + `inPath` 두 배열|
|두 그룹으로 나눌 수 있는가|BFS · DFS|`int[] color`|

### 정리
+ BFS · DFS의 골격은 그대로 두고 **`visited` 자리에 무엇을 기록하느냐**로 문제를 푼다
+ **거리를 기록하면** 최단 경로, **직전 정점을 기록하면** 경로 복원, **시작 횟수를 세면** 연결 요소다
+ 격자 문제는 인접 리스트가 없을 뿐 그래프다. **칸이 정점, 상하좌우가 간선**이다
+ 사이클 판별은 방향 · 무방향이 다르다 — **무방향은 부모 제외, 방향은 현재 경로(`inPath`) 확인**
+ 최단 경로에 BFS를 쓸 수 있는 건 **가중치가 없을 때뿐**이다
